# 🏙️ City Voice Dashboard

A modern, responsive civic engagement dashboard designed to manage city issues, track citizen reports, and monitor community metrics in real-time. Built with Next.js, TypeScript, and Tailwind CSS for a seamless user experience.

## ✨ Features

- **📊 Real-time Analytics:** Visualize civic engagement scores, active field workers, and total residents.
- **👥 User Directory:** Manage citizens, field workers, and admins with detailed profiles and status tracking.
- **🚧 Issue Tracking:** Detailed view of city issues (e.g., potholes, waste management) with resolution timelines.
- **💬 Citizen Discussion:** Integrated comment section for community feedback on specific issues.
- **🗺️ Interactive Maps:** Visual representation of issue locations and district-wise data.
- **🎨 Modern UI/UX:** Clean design using Framer Motion for smooth animations and transitions.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Package Manager:** pnpm
